# Taskline Mobile

[![CI](https://github.com/plucasr/taskline-mobile/actions/workflows/ci.yml/badge.svg)](https://github.com/plucasr/taskline-mobile/actions/workflows/ci.yml) [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Mobile client for **Taskline** — kanban boards on mobile, built with
[ReactLynx](https://lynxjs.org/) (Rspeedy).

## Features (planned)
- Board and card browsing against [taskline-api](https://github.com/plucasr/taskline-api)
- Card moves, comments, due dates
- Room chat (text)

## Stack
ReactLynx · Rspeedy · TypeScript

## Related
- API: [taskline-api](https://github.com/plucasr/taskline-api)
- Web: [taskline-web](https://github.com/plucasr/taskline-web)
